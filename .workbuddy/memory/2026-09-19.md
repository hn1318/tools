## 环境注意

- 本机 Bash 的 shim 会报 `dirname: command not found`，需要先 `export PATH="/usr/bin:/bin:$PATH"` 才能用 shell 命令。
- PowerShell 的文件删除被 safe-delete 钩子拦截（genie-trash 失败，拒绝回退删除），`Remove-Item` 会失败；bash `rm` 可用。且 `Remove-Item -Recurse` 可能只删掉部分文件，删完务必用 `git status` / Glob 复核。
- 验证方式：`npx vue-tsc --noEmit -p tsconfig.vitest.json --composite false`（约 30-50s）+ `npx vite build`，两者均通过。
- 遗留：`src/ui/*/*.demo.vue` 组件演示文件仍在（无引用，不影响构建），如需彻底清理可自行删除后重新 build 以刷新 `components.d.ts`。
