## 双语备忘录（cheatsheet）中英文切换
将用户此前要求翻译的几个工具改为「保留英文 + 中英文可切换」：

- **git-memo**：`git-memo.vue` 按 `locale` 在 `git-memo.content.md`(中文) 与新建 `git-memo.content.en.md`(英文) 间切换；`<component :is="Memo" />` 渲染。
- **docker-memo**：同上，`docker-memo.content.en.md` 新建英文版。
- **regex-memo**：`regex-memo.content.md` 改为中文（翻译描述 + 加量解释/提示），新建 `regex-memo.content.en.md` 英文版（同步补充提示）。切换逻辑同 git/docker。
- **http-status-codes**：`http-status-codes.constants.ts` 改为导出 `codesByCategoriesZh` / `codesByCategoriesEn` 两套并行数据；`.vue` 用 computed 按 locale 选数据集，搜索框与「搜索结果」标签通过 `$t('tools.http-status-codes.searchPlaceholder' / 'searchResults')` 本地化（已在 zh.yml / en.yml 增键）。`index.ts` 关键词改用 `codesByCategoriesEn`。
- 为使搜索在切换语言时同步刷新，将 `src/composable/fuzzySearch.ts` 的 `data` 参数由 `Data[]` 改为 `MaybeRef<Data[]>`，内部用 `computed(() => get(data))` 重建 Fuse 索引（对其它调用方向后兼容）。

切换约定：`locale.value` 以 `zh` 开头则中文，否则英文。
验证：`pnpm run typecheck` 通过；`vite build` 成功（`.content.en.md` 已被 markdown 插件正常编译）。
